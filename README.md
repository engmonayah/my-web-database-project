# my-web-database-project
This project is a webpage connected to a MySQL database done by infinityFree.
## Steps
1. I created a database using MySQL in InfinityFree.
2. I created a table called users.
3. The table has id, name, age and status.
4. I created a form to enter the name and age and status PHP is used to save the data in the database.
5. The saved data is displayed in a table.
6. I added a Toggle button to change the status between 0 and 1.
7. JavaScript is used to update the status without refreshing the page.
